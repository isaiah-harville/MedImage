# Model card: adrenalmnist3d-resnet18

## Summary
A 3D ResNet-18 that classifies AdrenalMNIST3D volumes (normal, hyperplasia) from 64³ inputs.
No run is published yet, so there are no results to report.

## Intended use
Research only. Not a medical device. Do not use it to diagnose or treat anyone, or on data
other than AdrenalMNIST3D volumes.

## Data
- AdrenalMNIST3D from MedMNIST v2 (Yang et al., Scientific Data 10:41, 2023,
  doi:10.1038/s41597-022-01721-8), the 64³ archive `adrenalmnist3d_64.npz` from Zenodo record
  10519652. Source: a new dataset by the MedMNIST authors: adrenal gland shapes from abdominal CT of 792 patients.
- License: CC BY 4.0 as declared by MedMNIST; there is no separate source license.
- Split: a random patient-level split by the MedMNIST authors. Train / val / test: 1,188 / 98 / 298
  volumes (`medmnist` metadata). MedMNIST publishes no patient IDs, so leakage cannot be
  checked.
- Labels: normal adrenal gland or adrenal mass, annotated by an expert endocrinologist.

## Training
Config: `config.yaml`, generated by `scripts/medmnist_recipes.py` (its docstring explains the
choices). MONAI ResNet-18 with 3D convolutions trained from scratch, AdamW, cosine schedule,
bf16 mixed precision, EMA weights, batch 16, 100 epochs; sized for a 12 GB GPU. Commit,
hardware, and training time: from the run's `run.json`.

## Limitations and biases
The input is a binary shape mask, not CT intensities. The validation split has only 98 volumes, so checkpoint selection is noisy.
The volumes are 64³ downsamplings, which lose fine detail.

## Reproduce
```bash
uv run opendiagnostics fit -c models/adrenalmnist3d-resnet18/config.yaml
```
