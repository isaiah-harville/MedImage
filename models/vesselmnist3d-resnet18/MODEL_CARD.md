# Model card: vesselmnist3d-resnet18

## Summary
A 3D ResNet-18 that classifies VesselMNIST3D volumes (vessel, aneurysm) from 64³ inputs.
No run is published yet, so there are no results to report.

## Intended use
Research only. Not a medical device. Do not use it to diagnose or treat anyone, or on data
other than VesselMNIST3D volumes.

## Data
- VesselMNIST3D from MedMNIST v2 (Yang et al., Scientific Data 10:41, 2023,
  doi:10.1038/s41597-022-01721-8), the 64³ archive `vesselmnist3d_64.npz` from Zenodo record
  10519652. Source: IntrA (Yang et al., 2020), brain vessel meshes reconstructed from MRA.
- License: CC BY 4.0 as declared by MedMNIST; IntrA's own terms are not stated on its repository.
- Split: a random 7:1:2 split by the MedMNIST authors. Train / val / test: 1,335 / 191 / 382
  volumes (`medmnist` metadata). MedMNIST publishes no patient IDs, so leakage cannot be
  checked.
- Labels: healthy vessel segment or aneurysm segment; segments were cut automatically from the complete vessel models.

## Training
Config: `config.yaml`, generated by `scripts/medmnist_recipes.py` (its docstring explains the
choices). MONAI ResNet-18 with 3D convolutions trained from scratch, AdamW, cosine schedule,
bf16 mixed precision, EMA weights, batch 16, 100 epochs; sized for a 12 GB GPU. Commit,
hardware, and training time: from the run's `run.json`.

## Limitations and biases
The input is a voxelized shape, not image intensities. Segments from one patient's vessel model may fall in different splits.
The volumes are 64³ downsamplings, which lose fine detail.

## Reproduce
```bash
uv run opendiagnostics fit -c models/vesselmnist3d-resnet18/config.yaml
```
