# Model card: totalsegmentator-dynunet

## Summary
TotalSegmentator 117-structure CT segmentation (DynUNet, 3 mm). Predicts 117 anatomical structures (organs, bones, muscles, vessels) from CT of any body region. No run has been published yet.

## Intended use
Research only. Not a medical device. Do not use it to diagnose, plan treatment or measure
patients.

## Data
- TotalSegmentator v2.0.1 (https://doi.org/10.5281/zenodo.10047292), 1,228 CTs. Download: `uv run python scripts/datasets/totalsegmentator.py data/totalsegmentator` writes `data/totalsegmentator/manifest.csv`.
  Download size: 23.6 GB zip.
- License: CC BY 4.0. Weights, predictions and example images may be published with attribution.
- Split: The dataset's own split from meta.csv (train, val, test). It publishes no patient IDs, so leakage between scans of one patient cannot be checked.
- Labels: Model-assisted annotation with manual review (Wasserthal et al. 2023); one mask per structure, merged by the script into one label map (later classes win on overlap).

## Training
Config: `config.yaml`, generated by `scripts/segmentation_recipes.py`. MONAI DynUNet, Dice
plus cross-entropy, SGD (Nesterov, momentum 0.99) with polynomial decay, bf16 mixed precision.
Volumes are resampled to 3 x 3 x 3 mm. Training takes 1 patch of 128 x 128 x 128
voxels per step from 1 volume, for 47 epochs. Inference is Gaussian-weighted sliding window with
half-patch overlap, and scoring happens on each label's original grid.

Estimated training memory at this patch and batch: 6.2 GiB (12.0 GiB measured for two 128³ patches, halved for the one patch this recipe uses; the 118-channel output and loss make up most of the gap to KiTS23's 4.9 GiB) (bytes autograd keeps
for backward under bf16 autocast plus fp32 weights, gradients and optimizer state, measured
on CPU; CUDA workspace and allocator overhead come on top). It is meant to fit a 12 GB GPU;
this has not been checked on one.

## Results
None yet. The headline is mean Dice over classes with a
95% patient-level bootstrap interval, from the run's `metrics.json`; per-case Dice and HD95
are in `predictions_test.csv`.

Published context: We train all 117 structures in one network at 3 mm, as TotalSegmentator's own fast model does (one network, all classes, 3 mm; Wasserthal et al. 2023, Supplement S4). The full-resolution model needs five 1.5 mm networks; one 1.5 mm network with 118 output channels would not fit 12 GB at a useful patch size. See `baselines.yaml` for what is comparable.

## Limitations and biases
Mostly one hospital and Siemens scanners. Labels were made with nnU-Net assistance. At 3 mm, small structures (adrenal glands, thin vessels, ribs) lose detail; the authors' 3 mm model scored Dice 0.840 against 0.943 at 1.5 mm on v1.

## Reproduce
```bash
uv run python scripts/datasets/totalsegmentator.py data/totalsegmentator
uv run opendiagnostics fit -c models/totalsegmentator-dynunet/config.yaml
```
