# Model card: kits23-dynunet

## Summary
KiTS23 kidney, tumor and cyst segmentation (DynUNet). Predicts kidney, renal tumor and renal cyst from contrast-enhanced abdominal CT. No run has been published yet.

## Intended use
Research only. Not a medical device. Do not use it to diagnose, plan treatment or measure
patients.

## Data
- KiTS23 (https://kits-challenge.org/kits23/), 489 public training cases. Download: `uv run python scripts/datasets/kits23.py data/kits23` writes `data/kits23/manifest.csv`.
  Download size: 42.1 GB of images (489 NIfTI files) plus the masks from the kits23 GitHub repository.
- License: CC BY-NC-SA 4.0. Weights and per-case predictions are derived works; non-commercial use only, share alike.
- Split: The 110 test cases' masks are hidden, so the 489 labelled cases are split 70/10/20 by patient (one case per patient), seed 0.
- Labels: Manual annotation by the KiTS team; 0 background, 1 kidney, 2 tumor, 3 cyst.

## Training
Config: `config.yaml`, generated by `scripts/segmentation_recipes.py`. MONAI DynUNet, Dice
plus cross-entropy, SGD (Nesterov, momentum 0.99) with polynomial decay, bf16 mixed precision.
Volumes are resampled to 1 x 1 x 1 mm. Training takes 2 patches of 128 x 128 x 128
voxels per step from 1 volume, for 147 epochs. Inference is Gaussian-weighted sliding window with
half-patch overlap, and scoring happens on each label's original grid.

Estimated training memory at this patch and batch: 4.9 GiB (bytes autograd keeps
for backward under bf16 autocast plus fp32 weights, gradients and optimizer state, measured
on CPU; CUDA workspace and allocator overhead come on top). It is meant to fit a 12 GB GPU;
this has not been checked on one.

## Results
None yet. The headline is mean Dice over regions with a
95% patient-level bootstrap interval, from the run's `metrics.json`; per-case Dice and HD95
are in `predictions_test.csv`.

Published context: On the hidden test set the KiTS23 winner (Myronenko et al.) reached mean Dice 0.835 over the three HECs; nnU-Net Revisited (Isensee et al. 2024, Table 1) reports 5-fold cross-validation HEC Dice of 86.04 to 88.67 for nnU-Net variants. Neither matches our split. See `baselines.yaml` for what is comparable.

## Limitations and biases
One institution's CTs for most cases; contrast phase varies. KiTS19/21/23 share cases, so do not mix editions.

## Reproduce
```bash
uv run python scripts/datasets/kits23.py data/kits23
uv run opendiagnostics fit -c models/kits23-dynunet/config.yaml
```
