# Model card: msd-liver-dynunet

## Summary
Medical Segmentation Decathlon Task03_Liver (DynUNet). Predicts liver and liver tumor from contrast-enhanced abdominal CT. No run has been published yet.

## Intended use
Research only. Not a medical device. Do not use it to diagnose, plan treatment or measure
patients.

## Data
- Medical Segmentation Decathlon Task03_Liver (http://medicaldecathlon.com/), labelled training cases. Download: `uv run python scripts/datasets/msd.py data/msd --task Task03_Liver` writes `data/msd/Task03_Liver/manifest.csv`.
  Download size: 28.9 GB tar (MD5-checked).
- License: CC BY-SA 4.0. Weights and predictions may be shared under the same license with attribution.
- Split: The test images' labels were never released, so the labelled training cases are split 70/10/20, seed 0. MSD publishes no patient IDs, so case IDs stand in for patients and leakage between cases of one patient cannot be checked.
- Labels: One annotator per task (Antonelli et al. 2022).

## Training
Config: `config.yaml`, generated by `scripts/segmentation_recipes.py`. MONAI DynUNet, Dice
plus cross-entropy, SGD (Nesterov, momentum 0.99) with polynomial decay, bf16 mixed precision.
Volumes are resampled to 1 x 1 x 1 mm. Training takes 2 patches of 128 x 128 x 128
voxels per step from 1 volume, for 544 epochs. Inference is Gaussian-weighted sliding window with
half-patch overlap, and scoring happens on each label's original grid.

Estimated training memory at this patch and batch: about 4.9 GiB (measured for KiTS23, which has the same network, patch and batch) (bytes autograd keeps
for backward under bf16 autocast plus fp32 weights, gradients and optimizer state, measured
on CPU; CUDA workspace and allocator overhead come on top). It is meant to fit a 12 GB GPU;
this has not been checked on one.

## Results
None yet. The headline is mean Dice over classes with a
95% patient-level bootstrap interval, from the run's `metrics.json`; per-case Dice and HD95
are in `predictions_test.csv`.

Published context: nnU-Net reports a mean Dice of 0.8111 in 5-fold cross-validation on all training cases and 0.86 on the hidden test set (Isensee et al., arXiv 1904.08128v2, Appendix F). Neither matches our split. See `baselines.yaml` for what is comparable.

## Limitations and biases
Small training sets for some tasks; one rater; MRI intensities were rescaled by the organisers.

## Reproduce
```bash
uv run python scripts/datasets/msd.py data/msd --task Task03_Liver
uv run opendiagnostics fit -c models/msd-liver-dynunet/config.yaml
```
