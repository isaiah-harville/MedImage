# Model card: fracturemnist3d-resnet18

## Summary
A 3D ResNet-18 that classifies FractureMNIST3D volumes (buckle rib fracture, nondisplaced rib fracture, displaced rib fracture) from 64³ inputs.
No run is published yet, so there are no results to report.

## Intended use
Research only. Not a medical device. Do not use it to diagnose or treat anyone, or on data
other than FractureMNIST3D volumes.

## Data
- FractureMNIST3D from MedMNIST v2 (Yang et al., Scientific Data 10:41, 2023,
  doi:10.1038/s41597-022-01721-8), the 64³ archive `fracturemnist3d_64.npz` from Zenodo record
  10519652. Source: RibFrac (Jin et al., 2020), chest CT.
- License: CC BY-NC 4.0, inherited from RibFrac (Zenodo record 3893508). MedMNIST declares CC BY 4.0. Non-commercial use only.
- Split: RibFrac's official train, validation and test split. Train / val / test: 1,027 / 103 / 240
  volumes (`medmnist` metadata). MedMNIST publishes no patient IDs, so leakage cannot be
  checked.
- Labels: buckle, nondisplaced, or displaced rib fracture, from the RibFrac annotations; each crop is centred on one fracture, and segmental fractures are dropped.

## Training
Config: `config.yaml`, generated by `scripts/medmnist_recipes.py` (its docstring explains the
choices). MONAI ResNet-18 with 3D convolutions trained from scratch, AdamW, cosine schedule,
bf16 mixed precision, EMA weights, batch 16, 100 epochs; sized for a 12 GB GPU. Commit,
hardware, and training time: from the run's `run.json`.

## Results

## Limitations and biases
Three fine-grained classes with 1,027 training crops, so published accuracy is near 0.5.
The volumes are 64³ downsamplings, which lose fine detail.

## Reproduce
```bash
uv run opendiagnostics fit -c models/fracturemnist3d-resnet18/config.yaml
```
